# 🎬 Lista de Filmes

> **Atividade Frontend** desenvolvida para exibição e gerenciamento de filmes.

---

## 📌 Sobre o Projeto

Aplicação web desenvolvida como atividade prática de Frontend, focada na construção de interfaces modernas, reutilização de componentes e manipulação de dados em Javascript/React.

---

## 🛠️ Tecnologias Utilizadas

* **[React](https://react.dev/)**
* **[Vite](https://vitejs.dev/)**
* **JavaScript (ES6+)** / **HTML5** / **CSS3**
* **ESLint** (Linter de código)

---
